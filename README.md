# SmartMemory plugins for Claude Code

The `smartmemory` plugin catalog.

## Install

```
claude plugin marketplace add smartmemory/claude-plugins
claude plugin install smartmemory-gtm@smartmemory
```

## Plugins

- `smartmemory-gtm`: research prospects, draft outreach, log touches and view your pipeline in the SmartMemory CRM. Setup and house rules are in [smartmemory-gtm/README.md](smartmemory-gtm/README.md). The CRM itself stays behind its own sign-in, so installing the plugin gives you the commands and the process, not any data.
